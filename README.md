# 혼알
매장 매뉴얼에서 근거를 확인하고, 해결되지 않은 질문을 사장님 문의함에 남기는 웹 앱.

## 실행
정적 서버로 루트 디렉터리를 제공합니다: `python3 -m http.server 8000`.
기본 상태는 개인 시연입니다. Firebase 연결 없이 매뉴얼·공지·버전별 읽음·문의함·사장 답변·실제 시연 활동 통계를 사용할 수 있습니다. 데이터는 현재 브라우저 localStorage에 저장합니다. 시연 상태에서 생성한 데이터는 다른 기기와 공유되지 않습니다. 기존 Firestore 루트 컬렉션을 수정하거나 삭제하지 않습니다.

## Gemini 및 공유 매장 활성화
1. Firebase 프로젝트 `honal-a0a82`의 App Check에 웹 앱과 reCAPTCHA Enterprise를 등록합니다. 허용 도메인에 `jiniyou04.github.io`를 등록합니다.
2. 공개 사이트 키만 `js/config.js`의 `appCheckSiteKey`에 넣습니다. Gemini API 비밀 키를 GitHub나 HTML에 넣지 않습니다. App Check enforcement를 끄지 않습니다.
3. Firebase AI Logic에서 Gemini Developer API가 연결되어 있고 설정한 모델을 사용할 수 있는지 확인합니다. 모델명은 `geminiModel`에서 조정합니다. 사전 테스트 없이 다른 모델로 자동 전환하지 않습니다.
4. Firebase Authentication의 익명 로그인을 활성화합니다. 프로덕션 운영 전에는 계정 연결·복구와 직원 탈퇴/초대 코드 회전도 추가해야 합니다. 익명 계정은 해당 브라우저 저장소를 지우면 복구할 수 없습니다.
5. `firebase deploy --only firestore:rules --project honal-a0a82`로 제공 규칙을 검토·배포합니다. 기존 루트 컬렉션 접근은 차단됩니다. 관리자 권한으로 필요한 기존 데이터를 먼저 백업/마이그레이션합니다. 클라이언트에서 기존 공유 데이터를 자동으로 가져오지 않습니다.
6. 규칙과 Auth를 검증한 뒤 `cloudEnabled:true`로 변경해 게시합니다. 두 브라우저로 매장 생성→초대 코드 참여→직원의 사장 편집 거부→다른 매장 접근 거부를 확인합니다.
7. Gemini 정상 응답, 근거 부족, App Check 실패, 한도 초과를 각각 확인합니다. API 비용과 요청량 제한은 Firebase/Google Cloud에서 관리합니다.

현재 App Check 공개 사이트 키가 제공되지 않아 Gemini 실호출 성공은 검증되지 않았습니다. 공유 매장은 서버 설정 전까지 비활성입니다. 이를 완료로 표시하지 않습니다.

## 답변 계약
AI는 자유로운 업무 답변을 쓰지 않고 관련 문서의 원문 인용을 선택합니다. 반환 인용이 실제 본문에 포함되어야만 표시합니다. 무관한 질문·불완전 근거·잘못된 응답·시간 초과는 답변 미확정으로 처리합니다. 이는 위험을 줄이는 장치이며 의미상의 오판을 완전히 없애는 보장은 아닙니다. 현재 검색은 동의어를 포함한 키워드 검색이며 임베딩 검색이 아닙니다.

미확정 질문은 저장이 성공한 경우에만 사장님 문의함 전달로 표시합니다. 문자/이메일/푸시는 발송하지 않습니다. 사장님은 앱 문의함에서 확인하며 직원은 공지 탭의 내 문의에서 답변을 확인합니다. 화면에 새로고침 버튼이 있고 공유 모드에서는 30초마다 갱신합니다.

## 변경점
- 고정 초대 코드/복사 성공 알림을 실제 생성·참여·클립보드 동작으로 교체(서버 설정 후).
- 로그인 없는 공용 컬렉션을 매장별 경로, 인증 UID와 역할 기반 규칙으로 분리.
- 데이터가 없을 때 100%, 최소 1명, 전환율 75/85% 등 허위 기본값 제거.
- 현재 버전+직원 단위 읽음 중복 제거, 공지 수정 후 재확인.
- HTML을 데이터로 처리하고 이벤트에 사용자 문자열을 직접 삽입하지 않음.
- 반복 시연/템플릿 적용 중복 방지, PDF 크기/페이지/텍스트 검사.
- 다른 매장 수로 오인하던 질문 횟수 및 합성 업종 통계 제거. 매장 간 집계는 동의·익명화·서버 집계를 검증하기 전 미제공.

## 검증
`npm test` / `npm run check`.
단위 테스트의 모델 응답은 고정된 테스트 대역입니다. Gemini 실호출 검증과 구분합니다.
